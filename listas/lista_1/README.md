# Lista de Exercícios 1 - Estrutura de dados

Reposítorio para a solução da lista 1 da matéria de estrutura de dados do curso de engenharia eletrôncia da UTFPR.


## Soluções das questões que não envolvem códigos

  12. Considere as seguintes afirmativas

   - I. Numa fila as inserções são realizadas em um extremo e as remoções no outro extremo.
   - II. A fila e a pilha são consideradas casos especiais da lista.
   - III. Numa fila a inserção e a retirada são feitas no mesmo extremo.
   - IV. Numa lista a inserção e a retirada podem ser feitas em qualquer posição.
   - V. Numa pilha apenas a inserção pode ser feita em qualquer posição.
Quais são as afirmativas verdadeiras?

  - [ ] a) Somente I e III
  - [ ] b) Somente II, III e IV
  - [x] c) Somente I, II e IV
  - [ ] d) Somente II, IV e V
  - [ ] e) Todas as afirmativas


  32. Uma estrutura de dados em lista duplamente encadeada permite na cadeia movimentos para

  - [ ] a) frente, apenas.
  - [ ] b) trás, apenas.
  - [ ] c) cima e para baixo ou para frente e para trás.
  - [ ] d) cima e para baixo, apenas.
  - [x] e) frente e para trás, apenas.

  34. Acerca de Estrutura de dados, assinale "V" para Verdadeiro e "F" para Falso:

  - [V] Na lista ligada, em cada nó possui um ou mais campos de informação e um apontador para o próximo nó da lista.
  - [F] Filas são estruturas de dados em que inserções são feitas no início e remoções são feitas no final das filas.
  - [V] Na lista ligada circular o último elemento aponta para o primeiro.
  - [V] Numa lista singularmente encadeada, para acessar o último nodo é necessário partir do primeiro e ir seguindo os campos de ligação até chegar ao final da lista.
  - [V] Uma lista é uma coleção de elementos do mesmo tipo dispostos linearmente, que podem ou não seguir determinada organização. As listas podem ser dos seguintes tipos: de encadeamento simples, duplamente encadeadas e ordenadas.
  - [V] Em uma lista circular duplamente encadeada, cada nó aponta para dois outros nós da lista, um anterior e um posterior.
  - [F] As pilhas são listas encadeadas cujos elementos são retirados e acrescentados sempre ao final, enquanto as filas são listas encadeadas cujos elementos são retirados e acrescentados sempre no início.
